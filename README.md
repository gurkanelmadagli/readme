# 🛡️ Defensive Security / Blue Team Portföyüm

 Bu repo, savunma güvenliği (Blue Team) alanındaki öğrenim sürecimi ve uygulamalı projelerimi içermektedir. Log analizi, SIEM kullanımı, IDS/IPS, olay müdahale ve güvenlik otomasyonu konularında yaptığım çalışmalara buradan ulaşabilirsiniz.

## 📌 İçerik Başlıkları

### 1️⃣ Sistem Log Analizi
- `windows-log-analysis/`: Event Viewer ile analizler, kullanıcı aktiviteleri, başarısız oturumlar
- `linux-log-analysis/`: auth.log, syslog incelemeleri, sudo kullanımları, şüpheli oturumlar

### 2️⃣ SIEM Kullanımı
- `wazuh-lab/`: Wazuh kurulumu, kurallar, alarmlar, örnek saldırı tespiti
- `splunk-scenarios/`: (varsa) Splunk dashboard ve alarmlar

### 3️⃣ IDS/IPS Uygulamaları
- `snort-rules/`: Basit Snort kural örnekleri
- `zeek-traffic-analysis/`: PCAP dosyaları üzerinden Zeek ile analizler

### 4️⃣ Ağ Trafiği Analizi
- `wireshark-pcaps/`: FTP, DNS, HTTP trafiği analizleri, flag çıkarma

### 5️⃣ Olay Müdahale (IR) Raporları
- `incident-response-reports/`: Simüle edilmiş saldırılar sonrası hazırlanan raporlar (Markdown veya PDF)

---

## 🛠️ Kullanılan Araçlar
- Kali Linux, Security Onion, Wazuh, Snort, Zeek, Wireshark
- Logstash, Splunk (demo), Sysmon, Event Viewer
